# Fatty Games branding

The Fatty Games signature was supplied by the project user for this application.

- `fatty-games-original.png`: original image, unchanged.
- `fatty-games-mask.svg`: an SVG rendering wrapper which uses the original ink as a mask. CSS displays the mark using the editor's current text color, so Light, Dark and imported themes all remain consistent.
- The logo appears in the editor header. It is not added to exported artwork.

Brand assets are separate from third-party fonts and icons. Including the logo with this application does not establish a separate reuse license for the brand.
